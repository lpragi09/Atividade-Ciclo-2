# Atividade-Ciclo-2

Projeto React feito na aula de Programação Web do Unilavras, com os cinco exercícios
do primeiro contato com componentes.

## Rodando o projeto

```bash
npm install
npm run dev
```

Depois é só abrir o endereço que aparece no terminal (normalmente http://localhost:5173).

## Exercícios

| Arquivo | O que faz |
| --- | --- |
| `src/Exercicio1.jsx` | Componente `Perfil` com nome e cidade |
| `src/Exercicio2.jsx` | Componente `Produto`, recebendo nome e preço por props |
| `src/Exercicio3.jsx` | `Avatar` e `InfoUsuario` compondo o `CardUsuario` |
| `src/Exercicio4.jsx` | `BotaoDownload`, que escreve no console ao ser clicado |
| `src/Exercicio5.jsx` | `ListaDeCompras`, renderizando um array com `.map()` |

Todos os componentes são importados e renderizados no `src/main.jsx`.

## Observações

- O exercício 4 mostra a mensagem `Iniciando download...` no console do navegador (F12).
- O exercício 3 usa uma imagem de https://placehold.co como avatar.

## Tecnologias

React 19 + Vite.
